역할

이 페이지는 파일 기반 해석 앱의 공통 처리 패턴만 기록합니다. Truss, Assessment, Scanner, ModelFlow 같은 개별 솔루션의 입력 파일 형식과 계산 상세는 별도 페이지에서 확장합니다.

1
파일 선택프론트엔드 페이지가 사용자의 입력 파일과 옵션을 수집합니다.
2
작업 요청/api/analysis/.../request 계열 API로 업로드하고 job_id를 받습니다.
3
백그라운드 실행백엔드가 작업 폴더를 만들고 서비스 함수 또는 외부 실행 파일을 실행합니다.
4
상태 조회프론트엔드가 상태 API를 폴링하고 진행률, 로그, 실패 메시지를 표시합니다.
5
결과 확인완료 후 결과 파일 경로와 요약 데이터가 DB에 저장되고 다운로드 또는 뷰어로 연결됩니다.
