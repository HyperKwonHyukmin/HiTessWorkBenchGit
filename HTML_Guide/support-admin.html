역할

이 페이지는 운영 기능의 공통 흐름만 기록합니다. 각 관리 화면의 필드, 권한 예외, 통계 산식은 필요할 때 상세 페이지로 분리합니다.

1
권한 확인관리자 기능은 is_admin과 보호 메뉴 목록을 기준으로 접근을 제어합니다.
2
운영 데이터 조회공지, 가이드, 요청, 사용자, 사용량 데이터를 API로 조회합니다.
3
CRUD / 승인관리자가 데이터 생성, 수정, 삭제, 승인, 코멘트 처리를 수행합니다.
4
활동 기록중요 작업은 활동 로그나 사용량 리포트의 기준 데이터가 됩니다.
