역할

이 페이지는 대화형 앱의 공통 화면 구조와 상태 흐름만 기록합니다. 개별 계산식, 입력 검증, 결과 해석은 솔루션별 문서로 분리합니다.

1
입력 상태폼, 선택값, 뷰어 상태를 페이지 state 또는 Context에서 관리합니다.
2
검증입력 범위와 필수값을 화면에서 먼저 검토하고 계산 가능 상태를 만듭니다.
3
계산/미리보기프론트엔드 계산 또는 짧은 API 호출로 결과를 즉시 갱신합니다.
4
결과 표시표, 요약 카드, 뷰어, 판정 상태를 같은 화면에서 확인합니다.
