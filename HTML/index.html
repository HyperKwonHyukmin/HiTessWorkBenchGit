Workbench 페이지에는 공통 구조만 기록합니다. 각 Studio와 상세 솔루션의 입력, 계산, 결과 흐름은 이후 별도 문서로 나눠 관리합니다.

문서화 목적

화면 흐름 추적 NavigationContext, App.jsx 라우팅, 공통 Context를 기준으로 화면 진입 경로를 파악합니다. Studio 흐름 분리 대분류 페이지에서 공통 패턴을 보고, 상세 솔루션 페이지로 확장합니다. 데이터 흐름 추적 SQLAlchemy 모델, 주요 테이블, 화면과 DB의 연결 관계를 정리합니다.

작성 단위

1
Home 전체 문서 인덱스와 메뉴를 관리합니다.
2
Workbench Electron, React, FastAPI, DB의 공통 골격과 변경 시 확인할 기준을 기록합니다.
3
Studio File-Based, Interactive, Parametric, Productivity, Support, Administration 영역별 흐름을 분리합니다.
4
Solution Detail 개별 솔루션의 입력, API 요청, 서비스 처리, 결과 표시, 파일 입출력을 기록합니다.
