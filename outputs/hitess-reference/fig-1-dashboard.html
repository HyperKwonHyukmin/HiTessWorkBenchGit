실제 실행 화면 — Dashboard. 데스크탑(Electron) 앱으로 실행되며 팀 공용 서버와 통신합니다.

화면 구성

1

해석 앱 내비게이션

File-Based · Interactive · Parametric · Productivity 등 카테고리별로 해석 앱을 모아 한 곳에서 진입합니다.

2

전역 검색 · 최근 사용 앱

메뉴와 앱을 단축키로 검색하고, 최근 사용한 해석으로 바로 복귀합니다.

3

작업 컨텍스트

현재 사용자와 접속 중인 해석 서버를 항상 표시해, 어디에 제출하는지 헷갈리지 않게 합니다.

4

서비스 현황

해석 서버 구동 수와 대기 큐, 실행 건수를 함께 드러냅니다. 상태를 숨기지 않는 것이 신뢰의 조건입니다.

5

즐겨찾기

자주 쓰는 해석 앱을 고정해 반복 작업의 진입 경로를 줄입니다.

6

프로젝트 이력

제출한 해석의 모듈·진행 상태·수행 일시를 이력으로 남기고, 결과 파일을 내려받습니다.

해석 작업 흐름

01

업로드

CSV · BDF 등 입력 파일을 해석 앱에 제출합니다.

02

큐 제출

작업이 서버 큐에 등록되고 최대 5건이 동시에 실행됩니다.

03

해석 실행

사내 해석 프로그램과 MSC Nastran이 실제 계산을 수행합니다.

04

진행 추적

진행률을 주기적으로 조회해 0~100%로 표시합니다. 페이지를 벗어나도 상태는 유지됩니다.

05

결과 확인

결과를 이력에 남기고 파일 다운로드 · Excel 내보내기로 반출합니다.

STACK Electron · React · FastAPI · MySQL · MSC Nastran
